# Images

## Header & footer avatars (stickers)

- **Header (nav):** `avatar-sticker-header.png` — e.g. waving Memoji (shown small, circular).
- **Footer:** `avatar-sticker-footer.png` — e.g. heart-hands Memoji (shown large, circular).

Use square PNGs (e.g. 512×512 or 1024×1024). PNG with transparent background works best (e.g. Memoji sticker export from iPhone).
